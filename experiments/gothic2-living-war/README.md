# Живой Хоринис: правила первого прототипа

Цель: отдельный некоммерческий мод для **Gothic II: Ночь Ворона**, не перенос браузерного рендера. Мод использует установленную игру; оригинальные архивы, модели, голоса и карты не входят в Git.

Первый срез: **ополчение Хориниса против наёмников Онара**. Одна застава на дороге у фермы Бенгара. В первый день запас у сторон разный. Дежурство истощает запас гарнизона, другая сторона готовится к вылазке; доставка провианта меняет исход. Без вмешательства игрока застава тоже переходит из рук в руки. Ничья оставляет контроль защитникам. После столкновения две игровые ночи передышки. Это правила для сценарного теста, не обещание, что в базовой игре есть такая готовая механика.

## Что есть в папке

- `LivingKhorinis.d`: изолированные переменные и правила в подмножестве Daedalus. Не заменяет ни одной функции оригинала. `Begin(day)` инициализирует отдельную игру ровно один раз; `Advance(day)` обрабатывает только ещё не обработанные дни; `Deliver(side)` меняет запасы. Адаптер отвечает за дедупликацию конкретных рейсов, перехват времени и сохранение.
- `node --test rules.test.mjs`: выполняет то же ядро через минимальную трансляцию синтаксиса в JavaScript. Это тест правил, **не компиляция Gothic, не установочный мод**.

## Дальше: подключение к Gothic II

1. Первая цель — оригинальная Gothic II: Night of the Raven на ПК, отдельное тестовое сохранение, без других больших модов. Выбрать точные waypoint'ы вне сцены оригинального квеста Бенгара в G2MDK/Spacer и проверить связанные маршруты. В диске игрока оставить исходные файлы нетронутыми.
2. Собрать модульную оболочку Ninja с G2 NotR скриптами. Начать с одного таймера: сверять игровой день, сохранять числа состояния и выводить владельца заставы для QA. Не перезапускать кампанию при загрузке или переходе между мирами.
3. У двух новых патрулей использовать стандартные модели, анимации и броню. Вне экрана решать исход правилами, рядом материализовать отряды и показать смену постов; применять результат ровно один раз по номеру ревизии. Не менять глобальную враждебность гильдий и не использовать квестовых актёров как бойцов.
4. Проверить запуск и сохранение на Windows: восемь игровых дней без игрока, доставка припасов, один видимый конфликт, уход с карты и возврат, выход в меню и загрузка. Только после этого выпускать готовый пак или готовить Workshop отдельно.

Документация: [официальное руководство Workshop](https://steamcommunity.com/sharedfiles/filedetails?id=2779846714), [Ninja и работа с NPC](https://github.com/szapp/Ninja/wiki/Applications-and-Examples#add-new-npc), [распорядок NPC](https://auronen.cokoliv.eu/gmc/zengin/scripts/externals/npc/#npc_exchangeroutine).
