# Следующий этап: фракции и реакции NPC

Запрос Ремзи: игрок может возглавить несколько фракций одновременно, отдавать приказы; армии пополняются крестьянами, перебежчиками из банд и новыми персонажами; патрули определяют контроль территорий. Все NPC должны реагировать на действия героя помимо стандартных сценариев. Текстовые реакции через OpenRouter, опция ключа в меню и бесплатная NVIDIA Nemotron. Ниже требования, не список уже выпущенных возможностей.

## Слой мира (работает без сети)

1. **События героя и свидетели.** Кладём в журнал игровые события (помощь, кража, драка, поставка, вступление, приказ). NPC реагируют лишь на то, чему были свидетелями или что дошло как слух; близкие реакции сразу, слухи по связи с поселением. Сохранять штатные реакции и диалоги, не дублировать наказания. Отдельно пометить оригинальных квестовых персонажей: без случайного рекрутинга, перезаписи распорядка или устранения в фоновой симуляции.
2. **Командование.** Лидерство хранится по каждой фракции отдельно, а не одним слотом. Доступ к приказу проверяется в момент исполнения по актуальному статусу. Лояльный NPC выполняет допустимый приказ в пределах своей роли и ресурсов; без ресурса или при конфликте двух приказов есть явный отказ и причина. Общая власть над двумя сторонами не сливает их автоматически.
3. **Люди, а не безлимитный спавн.** Крестьянин добровольно вступает при согласии, наличии снабжения/жалования и свободного места; уходит из гражданского пула и сохраняет идентичность. Бандит может перебежать или быть принят после амнистии. Новые свободные NPC появляются ограниченно, с уникальным ID, происхождением и ролью. Потери и увольнения учитываются, при перезагрузке нет повторной выдачи или дубля персонажей.
4. **Контроль через дороги.** Узлы (пост, хутор, перевал) и маршруты; отряды действительно проходят связанные waypoints. Патрули, припасы и непрерывность снабжения определяют присутствие и возможность удерживать узел. Захват не меняет владельца с пересечением невидимой линии; нужны превосходство и время удержания. Далеко считаем события по игровым часам, рядом показываем движение, смену формы/караула и последствия. Новый приказ: патруль, сопровождение, укрепление, отход. Сохранять журнал исходов для проверки.
5. **Первый тест.** Две фракции, два маршрута, один спорный пост: получить лидерство в каждой отдельно, выдать патрулю приказ, завербовать одного добровольца и перебежчика, перейти в другой мир/вернуться, сохранить/загрузить без дублей. Один исход без участия игрока, один с его вмешательством.

## Текст через OpenRouter (всегда необязателен)

- Настройки «ИИ-диалоги» выключены по умолчанию. Ключ пользователя вводится в отдельном поле в игре/лаунчере, держится в памяти вкладки, не записывается в Git, логи, save-файлы или адрес страницы. Выход, очистка и перезагрузка убирают ключ. Не запрашивать ключ в чате.
- Первая модель для теста: [NVIDIA Nemotron 3.5 Lightning (free)](https://openrouter.ai/nvidia/nemotron-3.5-lightning%3Afree). Только модель с суффиксом `:free`, без платной подмены. Ограничение частоты, бюджет запросов и тайм-аут; без ответа или при исчерпании квоты подставляется штатная реакция.
- В запрос передаём только минимальное вымышленное состояние персонажа и событие. На бесплатном endpoint нельзя отправлять конфиденциальные/личные сведения (заметка NVIDIA в карточке модели). Никаких сохранений целиком, файлов Steam, настоящих имён, голосов, изображений или ключа внутри промпта. Для первого теста только системные игровые события, не произвольный пользовательский текст. Информировать игрока, что этот текст отправляется внешнему провайдеру.
- Никакого фонового запроса за каждого NPC. Вызов только когда игрок общается или видит существенную реакцию, с кэшем по событию. Код отвечает за результат и действия; модель получает сводку, возвращает только реплику и, опционально, эмоцию из фиксированного списка. Ответ отображается текстом. Любая попытка изменить состояние, вызвать команды или внедрить разметку игнорируется.
- Нужен отдельный мост диалогов Daedalus → Web UI и обратная передача только реплики. Не менять CSP лаунчера, пока фича не соединена с игровым тестом. Тестировать заглушкой без ключа, затем ограниченным реальным запросом после ввода ключа владельцем.
