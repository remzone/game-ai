# Проверки при подготовке alpha 0.1

Дата: 2026-09-19. Среда: Linux, Node.js v24.19.0, npm 11.9.0.

## Выполнено

- `npm install` — зависимости установлены, package-lock.json создан.
- `npm run db:generate` — Prisma Client 6.19.0 сгенерирован.
- `npm run check` — TypeScript engine/server/client и production Vite build прошли; **17 тестов прошли**.
- Один интеграционный PostgreSQL test пропущен, так как TEST_POSTGRES не установлен и PostgreSQL недоступен.
- Реальный HTTP smoke в одном процессе с Fastify listen: New Game → enter → buy → save → sell → load. Баланс и RNG восстановлены.
- Собранный React/Phaser клиент отдаётся сервером по HTTP.
- Save/load проверен через FileStorage и gzip/checksum codec; продолжение детерминированной симуляции совпадает после загрузки.
- OpenRouter проверен через mock structured response: принятие, отклонение, cooldown, недоступность API. Реальный платный вызов не выполнялся, ключ не предоставлен.
- Валидация команд, отсутствие мутации на неверной команде, набор/демобилизация личностей и боевые смерти покрыты тестами.
- Установка пароля, сессионный доступ и запрет постороннего Origin покрыты тестом.
- Выполнена проверка исходников на очевидные приватные ключи/токены; реальных секретов нет. `.env` и данные игр исключены из Git/Docker.

## Не выполнено в этой среде

- `docker compose up` и настоящая PostgreSQL migration/round trip: Docker и PostgreSQL не установлены.
- Визуальная проверка в браузере: управляемый браузер блокирует адрес `http://127.0.0.1:3000` (`ERR_BLOCKED_BY_CLIENT`).
- Реальный OpenRouter запрос.
- Результат GitHub Actions в этой проверке не подтверждался.

В `.github/workflows/ci.yml` подготовлены gates PostgreSQL и Docker Compose + HTTP smoke. Само наличие workflow не означает, что эти проверки уже прошли.

- Обновлены действующие `main.tsx`, `style.css`, `game.tsx`, не отдельная демонстрационная страница.

- Типы React/Phaser проверены production build. Изменений модели сохранений, API и механики симуляции нет.
