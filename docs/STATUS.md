# Текущее состояние игры

Дата: 2026-09-20. Формат мира: **v4**. Исходные требования: `MASTER_PROMPT.ru.txt`.

Основной игровой цикл расширен до владений, областной и верховной власти, осад и продолжения династии. Это запускаемая игровая версия, **не утверждение о выполнении всех деталей исходного ТЗ**. Ниже механики отделены от оставшихся расширений и непроверенных условий развёртывания.

## Реализовано

- [x] Создание героя, сохранённая биография, параметры, навыки, родители, расы и смешанное ancestry.
- [x] Фиксированный континент: 300 исходных поселений, 50 областей, 10 держав; реальные жители, дороги, сезоны, календарь и ускорение времени.
- [x] Путешествия по дорогам, диалоги с местными NPC, торговля, оплачиваемая работа, отдых, лечение и помощь зерном.
- [x] Журнал контрактов: доставка и устранение существующей угрозы; заработанная награда сохраняется до выплаты.
- [x] Реальные отряды до 60 бойцов, снабжение, дезертирство, возвращение к профессиям и персональные боевые потери.
- [x] Смешанные классы: пехота, копья, лучники, конница, маги. Лошади учитываются при обучении, пополнении, гибели и роспуске.
- [x] Отдельная real-time сцена боя: движение, атака, удержание, контрбонусы, опыт и классы конкретных бойцов.
- [x] Волки, пауки, тролли, драконы: отдельные параметры/спрайты, локальная численность; рост и расселение популяций.
- [x] Репутация → защитник → управляющий поселением → глава области → верховная власть при признании большинства областей и выполнении политических условий.
- [x] Местные сборы, общественное строительство, реальные материалы и оплата работников; отзыв мандата после 14 дней недоверия.
- [x] Наследственные монархии и выборные правительства. В голосовании участвуют реальные областные руководители; разные формы учитывают службу, богатство, армию, родство, верование или магическое обучение.
- [x] Законы равного/старшего наследования, веротерпимость, реформа строя с потерей легитимности и лояльности.
- [x] 30 дней массового недовольства → отделение области, организация реальных руководителей, новая держава и переход контроля объектов.
- [x] Территориальные претензии из-за дефицита, объявление войны, мир, союзы, торговые соглашения и право прохода с ограниченным сроком.
- [x] Государственные армии из реальных жителей, оплата из казны и движение по дорожным маршрутам. Право прохода проверяется во всех областях маршрута.
- [x] Автономные походы к объявленной территориальной цели: оплата мобилизации, резерв зерна для жителей, физический походный запас, марш, блокада и штурмы с персональными ранениями/смертями. Завершение по достижению цели или после 180 дней, перемирие и возвращение армий по дорогам.
- [x] До трёх осадных машин: реальное дерево, железо и инструменты из инвентаря; рост давления и снижение морали гарнизона. Вылазка героя с настоящим гарнизоном снимает вражескую осаду при победе.
- [x] Осада: реальный гарнизон, блокада дорог, голод, давление, капитуляция, снятие осады и тактический штурм.
- [x] Укрепления снижают урон защитникам. Через 14 дней после захвата центра деревни проверяют лояльность и реальный гарнизон: верные прежней державе сопротивляются, оккупационный отряд снижает сопротивление, возврат центра отменяет аннексию.
- [x] Фермы, шахты, мастерские: реальные работники, зарплата, отдельные склады/касса, выделение доли фактически произведённого товара; голодная кузня не создаёт оружие из старых запасов.
- [x] Перевозка зерна и промышленных товаров реальными караванами. Охрана существующего опасного рейса снижает риск и оплачивается только после доставки.
- [x] Основание деревни: 10 переселенцев с сохранением ID, зерно и деньги переносятся из исходного поселения; новые дорожные соединения расходуют материалы.
- [x] Деньги, товары и владения распределяются между наследниками. Новый герой использует собственные навыки; остальные наследники остаются NPC со своей долей.
- [x] Признание наследника через доверие и оформление; продолжение только за живого взрослого преемника.
- [x] Наследуемый магический потенциал, живые учителя, платное обучение с расходом времени, две школы (стихии/лечение), мана и проверка цели/дальности заклинания. Боевые маги расходуют свою ману.
- [x] Три верования, передача по семье, смена верования героя; запрет иных верований снижает лояльность их последователей.
- [x] Исторические факты и субъективные хроники раздельны. Whitelist: хроника, прозвище, почётный титул, продовольственный контракт, подтверждённая претензия, организация существующих руководителей.
- [x] OpenRouter получает ограниченный контекст и структурированную схему; все предложения повторно валидируются движком, почётный титул не даёт полномочий.
- [x] Интерфейс «Жизнь и власть», совет, смешанный отряд, магия в бою, армии/осады на карте; полная история и список жителей доступны постранично.
- [x] 5 ручных слотов и autosave, checksum, RNG, миграции v1 → v2 → v3 → v4; ошибка записи не превращает выполненную команду в ложный отказ.
- [x] Локальные Prisma generation, production build, тесты и реальный HTTP smoke на одноразовом файловом хранилище.

## Проверки

- **67 тестов прошли**, один PostgreSQL-тест пропущен. Точная команда: `npm run check`.
- Дополнительный HTTP сценарий: создание → работа → покупка владения → сохранение → изъятие денег → загрузка; проверены архив и отдача клиента. Команда: `node --import tsx scripts/release-smoke.ts`.
- Миллион жителей проверен за 1080 игровых дней. Измерения и ограничения — в `VALIDATION.md`.
- GitHub CI пропускается по просьбе владельца.
- [ ] Docker Compose и PostgreSQL: в рабочей среде нет Docker/psql; эту проверку не считать пройденной.
- [ ] Визуальная браузерная и мобильная приёмка пропущена по прямой просьбе владельца. Это не препятствует доработке кода и не считается пройденной проверкой.
- [ ] Реальный оплачиваемый OpenRouter-вызов: проверен mock провайдера, не настоящий запрос.
